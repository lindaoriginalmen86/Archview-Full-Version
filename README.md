## 📖 Overview
<a id="overview"></a>

**ArchView** is a powerful Firefox add-on designed for Windows that allows you to inspect the contents of ZIP, RAR, and ISO files before downloading them. With **ArchView**, you can ensure that what you’re downloading is exactly what you need, enhancing your online safety and saving you time. The **latest version** of ArchView is packed with features that make checking the contents of compressed files a breeze.

By utilizing **ArchView**, you can avoid the uncertainty that often comes with downloading compressed files from the internet. This **full version** provides complete functionality, ensuring you have all the tools needed to make informed decisions about your downloads.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Preview Contents** — View the contents of ZIP, RAR, and ISO files before downloading to ensure they are safe.
- **Individual File Download** — Download specific files from within compressed archives directly.
- **Protocol Compatibility** — Works seamlessly with HTTP, FTP, and FILE protocols.
- **Enhanced Viewing Options** — Displays information in XUL or HTML format in a new Firefox tab.
